# Hash Checker

## Objective

The objective of this script is to calculate the hash value of a file using MD5, SHA1, or SHA256.

## Tools Used

- Python
- hashlib library

## Security Relevance

Hashing is commonly used in cybersecurity to verify file integrity, compare known malicious files, and support forensic investigations.

## How It Works

The script reads a file in chunks and calculates a hash value using the selected hashing algorithm.

## Example Use Cases

- Verify that a downloaded file has not changed
- Compare a file hash against known indicators of compromise
- Support basic forensic documentation

## Lessons Learned

This project helped reinforce how hashing supports file integrity and incident response workflows.
