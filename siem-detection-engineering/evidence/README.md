# Evidence

This folder contains screenshots and supporting evidence from the Microsoft Sentinel SIEM lab.

The screenshots document the progression from telemetry ingestion through detection, alert generation, incident creation, and investigation.

## Evidence Index

1. **PowerShell Event Ingestion**
   - Event ID 4104 successfully ingested into Microsoft Sentinel.

2. **KQL Detection**
   - Suspicious PowerShell test activity identified using KQL.

3. **Analytics Rule**
   - Scheduled Microsoft Sentinel analytics rule configured for the PowerShell detection.

4. **Defender Alert**
   - Microsoft Defender XDR alert generated by the Sentinel analytics rule.

5. **Incident Validation**
   - Incident existence verified using the `SecurityIncident` table.

6. **Process Correlation**
   - Event ID 4688 used to correlate `cmd.exe` with `powershell.exe`.

7. **Logon Investigation**
   - Event ID 4624 used to identify the remote interactive session and associated Logon ID.

8. **Process Timeline**
   - Process activity associated with the session reconstructed using Event ID 4688.

## Privacy

Screenshots are sanitized before publication to remove or obscure:

- Subscription IDs
- Email addresses
- Public IP addresses
- Azure resource identifiers that are not necessary to demonstrate the investigation
- Authentication details
- Any other personally identifying information
